- 修正 Antigravity 2.28.2 的实际结束原因：正常短回复使用 `NO_TOOL_CALL`，不再因与网页示例不同而显示未知。

- 新增并安装 Devin Local 独立事件桥，覆盖提交任务、需要授权、工具活动、Stop；不返回审批决定。
- 防止 Devin 默认导入 Claude 配置时产生错误的 Claude 记录；保留用户的配置导入偏好。
- 加固安装/卸载：保护未标记文件、保留其他 handler 和自定义字段、拒绝有损改写带注释配置、白名单解析与超限输入放弃。
