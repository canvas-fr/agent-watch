# Agent Watch 0.2.1 功能进展与验收

记录时间：2026-11-04T01:44:48.520721+08:00。

**当前为可用预览版，八款软件全部可靠监控尚未完成。** 开发顺序按用户要求：先实现功能，日后视觉参考 CC Switch；平时使用 macOS 状态栏，点击后展开详情。

## 本次实现

- 状态栏动态摘要：运行、待处理、新结束；无可靠状态时明确显示未确认。
- 未读结束记录持久化，标记已读前保留；同一应用/会话/轮次去重。
- 进行中状态过期后标为未知，已确认的结束、失败和取消保留为历史事实。
- 持续事件采集、菜单栏面板、系统通知、暂停、状态导出和打开客户端。
- 子代理按自己的会话结束，普通 Stop 不覆盖更明确的失败/取消结果。
- 文件队列扫描有界；坏文件不会堵死合法事件；离线缓冲的合法事件保留并按时间判断是否提醒。
- 窗口扫描身份修正：不会因临时辅助功能对象变化不断生成假会话；无法区分多窗口时保留不确定性。
