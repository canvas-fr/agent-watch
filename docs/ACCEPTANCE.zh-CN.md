# Agent Watch 第 0 阶段验收

> 本文保留第0阶段探测器的验收模板。0.2.0 的发布验收另见 RELEASE-0.2.zh-CN.md；没有填证据的旧条目仍不视为通过。

## 验收范围

当前确认落地的范围为：只读安装/运行元数据、可选的 macOS 辅助功能（Accessibility，AX）角色统计，以及明确文件路径存在性元数据。下表是验收标准，不代表每项已经完成实测；未附证据的项目保持“待记录”。

## 验收清单

| 编号 | 验收项 | 通过条件 | 当前记录 |
| --- | --- | --- | --- |
| 0.1 | 安装与运行元数据 | 只报告约定的元数据；不把应用进程存活解释为任务仍在运行 | 待记录 |
| 0.2 | 可选 AX 角色统计 | 用户未授权、接口不可用或采集失败时明确显示不可用/未知；不伪报为零 | 待记录 |
| 0.3 | 路径存在性元数据 | 仅检查并记录明确指定路径是否存在；不打开或解析文件内容 | 待记录 |
| 0.4 | 内容边界 | 不读取聊天正文，不读取或采集截图 | 待记录 |
| 0.5 | 只读边界 | 不写入应用配置、不触发应用操作、不激活或切换应用 | 待记录 |
| 0.6 | 能力声明 | 文档、界面及演示不声称任务适配、后台完成识别或 parent/subagent 跟踪已完成 | 待记录 |
| 0.7 | 可复核记录 | 对每项验收提供日期、系统/应用版本、授权状态、观察结果和证据位置；敏感内容不进入证据 | 待记录 |

## 不属于第 0 阶段的验收

以下内容须在后续阶段分别测试，不能用第 0 阶段的安装或进程数据代替：

- 运行、等授权、等回答、本轮结束、失败、取消等任务状态识别。
- 前台和后台状态追踪、断线恢复、事件去重与乱序处理。
- 多窗口、多个会话及 parent/subagent 的正确区分。
- 目标应用或模式的适配覆盖率及后台任务完成判定。
